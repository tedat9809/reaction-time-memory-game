# reactiontimememorygame_BCS200-FinalProject-
BCOG 200 final project
## Project Description
This project will be a Python program that includes small cognitive mini-games focused on reaction time and short-term memory. The user will interact with the program through the terminal and complete different challenges that test their speed and memory. The program will record results from each round and calculate simple performance statistics. The goal of the project is to create an interactive cognitive game using Python while practicing loops, conditionals, and modular code design.

## Planned Functions

### run_reaction_test()
This function will create a reaction time test by waiting a random amount of time and then prompting the user to respond. It will measure how long it takes the user to react.

### run_memory_test()
This function will display a short sequence of numbers or letters for the user to remember. The user will then enter the sequence, and the program will check if the answer is correct.

### summarize_results()
This function will take the results from the different tests and calculate statistics such as average reaction time and number of correct memory answers. It will then display a summary of the user's performance.
